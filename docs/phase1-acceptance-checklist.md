# Phase 1 受け入れ試験チェックリスト

Phase 1の完了判定に使う実機・実運用向けの確認項目。実施日、端末、結果、発見したIssueを記録する。

## 事前準備

- [ ] 公開版と同じGitHub Pages URLをAndroid Chromeで開ける
- [ ] テスト用Roomと4人のプレイヤー名を用意する
- [ ] JSONバックアップを保存できる場所を用意する
- [ ] 共有確認を行う場合、GAS同期を利用できるGoogleアカウントを準備する

## 基本記録

- [ ] Roomを作成できる
- [ ] 対局日を追加・選択・削除できる
- [ ] 4人の合計が100000点の半荘を保存できる
- [ ] 合計が100000点でない半荘を保存できない
- [ ] 保存済み半荘を編集・削除できる
- [ ] 日計、通算成績、場代が想定どおり表示される

## 同点処理

- [ ] 同着ルールで、ウマ・オカが対象順位に応じて平均される
- [ ] 席順ルールで同点者全員の順位を選択できる
- [ ] 席順ルールで順位が未選択・重複している場合に保存できない
- [ ] 3位・4位同点では、選択肢が3位・4位と表示される

## PWA・オフライン

- [ ] ホーム画面へ追加して起動できる
- [ ] オフラインで既存Roomを開ける
- [ ] 機内モード中に半荘を追加できる
- [ ] アプリを閉じて再起動しても、オフライン中に追加した半荘が残る
- [ ] 通信復帰後もローカル記録が失われない
- [ ] 新しい公開版へ更新した後、アプリを再起動して最新版を利用できる

## バックアップ・復元

- [ ] 選択中RoomのJSONを書き出せる
- [ ] 別ブラウザまたはシークレットウィンドウへ復元できる
- [ ] 復元後にRoom、対局日、半荘、ルール設定が一致する
- [ ] 壊れたJSONを読み込んでも既存データが変更されない

## GAS同期

- [ ] 端末Aからサーバーへ保存できる
- [ ] 端末Bから同じRoomをサーバーから取得できる
- [ ] 端末Aで保存後、端末Bが古いrevisionのまま保存すると競合表示になる
- [ ] 競合時、端末Bが取得して内容を確認した後に保存できる
