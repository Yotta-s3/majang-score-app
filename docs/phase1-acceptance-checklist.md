# Web/PWA 受入テストチェックリスト

## 事前準備

- [ ] GitHub Pagesの公開URLをAndroid ChromeまたはSafariで開ける
- [ ] テスト用ルームと4人のプレイヤー名を用意する
- [ ] JSONバックアップを保存できる場所を用意する
- [ ] 共有確認用に、別ブラウザまたは別端末を用意する

## 基本記録

- [ ] ルームを作成できる
- [ ] 対局日を追加・選択・削除できる
- [ ] 4人の合計100,000点の半荘を保存できる
- [ ] 合計100,000点でない半荘は保存できない
- [ ] 保存済み半荘を編集・削除できる
- [ ] 日別・通算成績、場代を確認できる

## 同点時の順位

- [ ] 同着ルールで同点の順位とポイントを確認できる
- [ ] 席順ルールで同点プレイヤーの順位を選択できる
- [ ] 順位未選択では保存できない
- [ ] 3位・4位の同点時にも順位候補が正しく表示される

## バックアップ

- [ ] 選択中ルームをJSONとして書き出せる
- [ ] 正常なバックアップを復元できる
- [ ] 壊れたJSONを読み込んでも既存データが変更されない

## Supabase同期

- [ ] 端末Aからサーバーへ保存できる
- [ ] 保存後に共有コードが表示・コピーできる
- [ ] 端末Bで共有コードを入力し、ルームに参加できる
- [ ] 端末Bで追加した対局日・半荘を端末Aが取得できる
- [ ] 同じルームを別端末で更新した後、古い端末の保存が競合として拒否される
- [ ] 競合表示後、「サーバーから取得」で同期状態を復帰できる
- [ ] Supabase未登録の既存ローカルルームを初回保存できる

## PWA・オフライン

- [ ] ホーム画面へ追加して起動できる
- [ ] オフラインで既存ルームを開ける
- [ ] 機内モード中に半荘を追加できる
- [ ] アプリを閉じて再起動しても、オフライン中に追加した半荘が残る
- [ ] 通信復帰後もローカル記録が失われない
- [ ] 新しい公開版への更新通知から最新版を利用できる
